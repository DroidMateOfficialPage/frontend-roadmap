# Korčula Romance — Premium Mediterranean Travel Showcase 🌅🍷

A high-end, editorial digital experience dedicated to luxury romance tourism, boutique heritage stays, and curated island experiences on the historic island of Korčula. Engineered with **Vite** and deployed on the edge.

Live Demo: [kor-ula-romance.ivana-08b.workers.dev](https://kor-ula-romance.ivana-08b.workers.dev/)

---

## 🌐 Overview

This repository showcases how to approach **luxury travel and destination UI/UX engineering**. It completely breaks away from generic, crowded tourism agency layouts, utilizing a sophisticated, Vogue-style editorial design that captures the romantic, stone-walled heritage of Korčula.

Instead of just listing sights, this is **experience-driven frontend architecture**:
- Heritage storytelling → Mediterraean minimalist tokens → Fluid layout depths → Premium UX

---

## 📦 Tech Stack & Infrastructure

- **Vite** (Next-generation frontend tooling & asset bundling pipeline)
- **HTML5** (Semantic Web Architecture & Accessibility)
- **CSS3** (Custom Properties, CSS Grid, Flexbox, Fluid Typography systems)
- **JavaScript (ES6+)** (Dynamic UI states, smooth scroll transitions & mobile interaction layers)
- **Cloudflare Workers** (Global edge computing deployment for lightning-fast loads)
- **SEO Basics** (Structured markup, Open Graph social sharing optimizations)

## 🚀 Key Features Implemented

### 1. Cinematic Heritage Hero Section

An ultra-lux, immersive entry layout utilizing precise text-tracking and warm, high-contrast imagery to instantly establish the island's romantic and premium identity.

### 2. Editorial Experience & Itinerary Layouts

Asymmetric grids and perfectly balanced text blocks that mimic high-end travel and luxury print magazines, keeping destination storytelling readable and captivating.

### 3. Interactive Romantic Curations Grid

A clean, JS-backed interaction layer allowing users to seamlessly preview bespoke romantic packages, boutique heritage accommodation, and premium winery tours.

### 4. Fluid Mobile Scaling

Engineered entirely with fluid typography and relative spacing tokens so the design retains its elegant, breezy, and high-end proportions on everything from mobile screens to ultrawide displays.

## 🧠 Learning Goals & Architecture Focus

This project was built to master:

* **Handling Heritage Luxury Aesthetics:** Balancing historic, stone-and-sea visual assets with minimal, ultra-clean UI spaces without breaking visual hierarchy.
* **Typographic Authority:** Perfecting tracking, kerning, and line-heights for clean sans-serif bodies and sophisticated display serifs that reflect old-world luxury.
* **Edge Performance Optimization:** Streaming heavy, high-res lifestyle imagery instantly across global edge nodes using Vite's bundling pipeline.

## 🔍 Performance & Web Fundamentals Practiced

* **Vite Build Optimization:** Automated code minification, bundle splitting, and caching-ready asset hashing out of the box.
* **Cloudflare Edge Infrastructure:** Deploying the compiled static builds directly to edge networks for global ultra-low latency.
* **Semantic HTML Construction:** Ensuring accessibility, clean structure, and optimal SEO indexation using proper tags (`<main>`, `<section>`, `<article>`).

## 🛠 How to Use & Modify This Repo

### 1. Clone the repository

```bash
git clone [https://github.com/DroidMateOfficial/korcula-romance.git](https://github.com/DroidMateOfficial/korcula-romance.git)
cd korcula-romance

```

### 2. Install development dependencies

```bash
npm install

```

### 3. Launch local Vite development server

```bash
npm run dev

```

### 4. Build optimized files for production

```bash
npm run build

```

*Vite will instantly compile and compress all assets into the `dist/` folder, ready for immediate Cloudflare deployment.*
