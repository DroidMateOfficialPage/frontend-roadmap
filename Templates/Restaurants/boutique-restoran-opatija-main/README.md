# Boutique Restoran Opatija — High-End Gastronomy Landing Page 🍽️✨

A premium, editorial digital experience for an upscale boutique restaurant in Opatija, engineered using **Vite** for maximum performance and deployed on the edge.  
This project focuses on translating fine-dining luxury into a clean, modern interface featuring precise typography hierarchy, sophisticated asymmetric layouts, and smooth interactions.

Live Demo: [boutique-restoran-opatija.ivana-08b.workers.dev](https://boutique-restoran-opatija.ivana-08b.workers.dev/)

---

## 🌐 Overview

This repository showcases how to approach **hospitality UI/UX engineering with a luxury mindset**. It skips standard restaurant template patterns in favor of a sleek, Vogue-style editorial layout that tells a story of culinary craftsmanship.

Instead of just building a basic digital menu, this is **brand-first frontend development**:
- Immersive storytelling → Elegant typography → Fluid layout transitions → High-converting UX

---

## 📦 Tech Stack & Infrastructure

- **Vite** (Next-generation frontend tooling & asset pipeline)
- **HTML5** (Semantic Web Architecture & Accessibility)
- **CSS3** (Custom Tokens, CSS Grid, Flexbox, Fluid Spacing)
- **JavaScript (ES6+)** (Dynamic menu states, scroll behaviors & smooth UI)
- **Cloudflare Workers** (Global edge computing deployment for lightning-fast loads)
- **SEO Elements** (Structured schema preparation, Open Graph performance)

## 🚀 Key Features Implemented

### 1. High-End Editorial Hero Section

An ultra-lux visual entry point that immediately sets the tone of a premium coastal dining experience using minimal layout components and cinematic spacing.

### 2. Digital Gastronomy Menu Component

A highly clean, structured, and easy-to-read menu component designed with strict typographic hierarchy, combining minimalist pricing structures and descriptive layout blocks.

### 3. Asymmetric Narrative Grids

Utilizing modern CSS Grid layouts to blend high-res imagery and culinary storytelling perfectly, mimicking high-end print design.

### 4. Flawless Mobile Responsiveness

Every section, from the complex dining gallery to the reservation call-to-actions, scales down gracefully to mobile screens without losing an ounce of its luxury appeal.

## 🧠 Learning Goals & Architecture Focus

This repository was created to master:

* **Typography Balance:** Managing tracking, line heights, and elegant serif/sans-serif pairings to establish immediate brand authority.
* **Visual Depth Control:** Using whitespace as a design element to create an "uncluttered, ultra-lux" feel.
* **Asynchronous Asset Optimization:** Leveraging Vite's build tools to handle heavy, high-res fine-dining imagery efficiently across global edge networks.

## 🔍 Performance & Web Fundamentals Practiced

* **Vite Production Bundling:** Automated CSS/JS minification and code optimization out of the box.
* **Cloudflare Edge Performance:** Ultra-low latency image delivery and content serving from any global edge node.
* **Semantic Structure Architecture:** Clean, SEO-optimized markup using structural HTML elements (`<main>`, `<section>`, `<article>`).

## 🛠 How to Use & Modify This Repo

### 1. Clone the repository

```bash
git clone [https://github.com/DroidMateOfficial/boutique-restoran-opatija.git](https://github.com/DroidMateOfficial/boutique-restoran-opatija.git)
cd boutique-restoran-opatija

```

### 2. Install development dependencies

```bash
npm install

```

### 3. Launch local Vite development server

```bash
npm run dev

```

### 4. Build optimized files for production

```bash
npm run build

```

*Vite will instantly build and optimize all assets into the `dist/` directory, ready to be picked up by Cloudflare.*
