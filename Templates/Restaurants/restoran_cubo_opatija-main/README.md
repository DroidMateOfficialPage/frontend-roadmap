# Restoran Cubo Opatija — Modern Avant-Garde Gastronomy 🍽️📐

A premium, design-forward digital experience for a contemporary fine-dining restaurant in Opatija, engineered with **Vite** and deployed on the edge.  
This project focuses on translating geometric architectural precision and avant-garde culinary art into a sleek interface, combining structured layouts, sharp typography, and high-end visual depth.

Live Demo: [restoran-cubo-opatija.ivana-08b.workers.dev](https://restoran-cubo-opatija.ivana-08b.workers.dev/)

---

## 🌐 Overview

This repository showcases how to approach **hospitality UI/UX engineering with a modern, structural luxury mindset**. It completely avoids traditional hospitality templates, utilizing a bold, geometric layout system inspired by high-end architectural design and Vogue-level editorial spacing.

Instead of just building a simple food website, this is **brand-first frontend engineering**:
- Structural storytelling → Bold geometric layouts → Sharp, elegant typography → Immersive UX

---

## 📦 Tech Stack & Infrastructure

- **Vite** (Next-generation frontend tooling & asset pipeline)

- **JavaScript (ES6+)** (Dynamic UI states, interactive menu layers & smooth scroll states)

- **SEO Basics** (Structured markup & metadata optimization)

## 🚀 Key Features Implemented

### 1. Structural Geometric Hero Section

An immersive, ultra-clean visual entry point that utilizes bold layout alignment and sharp grid discipline to immediately capture the restaurant's avant-garde identity.

### 2. Minimalist Contemporary Menu Component

A highly structured, pristine menu layout built with strict typographic hierarchy, designed to present curated fine-dining degustation sets cleanly and elegantly.

### 3. Cubist-Inspired Content Grids

Utilizing CSS Grid to build sharp, overlapping layouts and asymmetric image blocks, mirroring the high-end architectural styling of modern premium restaurants.

### 4. Flawless Mobile Scale System

Engineered with fluid typography and precise relative spacing tokens so the complex, structural design retains its perfect luxury proportions across all viewports.

## 🧠 Learning Goals & Architecture Focus

This project was built to master:

* **Grid Discipline & Asymmetry:** Mastering complex CSS Grid placements to achieve structural layout designs without breaking web usability.
* **Micro-Space Balancing:** Using precise line heights, high letter-spacing, and intentional whitespace to deliver an "uncluttered, elite" editorial look.
* **Edge Deployment & Speed Asset Management:** Routing high-res avant-garde culinary imagery seamlessly through Vite's bundling pipeline into Cloudflare's global edge network.

---

## 🔍 Performance & Web Fundamentals Practiced

* **Vite Production Bundling:** Automated bundle splitting, minification, and caching-ready asset hashing out of the box.
* **Cloudflare Edge Infrastructure:** Deploying optimized builds directly to global nodes for instant edge serving and ultra-low latency.
* **Semantic HTML Construction:** Ensuring accessibility and clean SEO indexation using structured structural tags (`<header>`, `<main>`, `<section>`).

## 🛠 How to Use & Modify This Repo

### 1. Clone the repository

```bash
git clone [https://github.com/DroidMateOfficial/restoran-cubo-opatija.git](https://github.com/DroidMateOfficial/restoran-cubo-opatija.git)
cd restoran-cubo-opatija

```

### 2. Install development dependencies

```bash
npm install

```

### 3. Launch local Vite development server

```bash
npm run dev

```

### 4. Build optimized files for production

```bash
npm run build

```

*Vite will compile and compress everything into the `dist/` folder, completely optimized for Cloudflare deployment.*
