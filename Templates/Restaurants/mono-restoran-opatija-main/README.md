# Molo Restoran Opatija — Coastal Gastronomy Experience 🌊🍽️

A premium, modern digital experience for an upscale waterfront restaurant located on the iconic pier in Opatija, engineered with **Vite** and deployed on the edge.  
This project focuses on translating nautical luxury and seaside dining into a sleek interface, combining fluid layouts, crisp typography, and high-end visual storytelling.

Live Demo: [molo-restoran-opatija.ivana-08b.workers.dev](https://molo-restoran-opatija.ivana-08b.workers.dev/)

---

## 🌐 Overview

This repository showcases how to approach **hospitality UI/UX engineering with a premium coastal branding mindset**. It breaks away from generic seafood restaurant layouts, using a modern, Vogue-style editorial design that channels the sophisticated energy of the Opatija lungomare.

Instead of just a basic landing page, this is **experience-driven frontend engineering**:
- Seaside storytelling → Minimalist layout aesthetics → Crisp, elegant typography → Immersive UX

---

## 📦 Tech Stack & Infrastructure

- **Vite** (Next-generation frontend tooling & asset bundling)
- **HTML5** (Semantic Architecture & Web Accessibility)
- **CSS3** (Custom Properties, Fluid Typography, Flexbox, Advanced Grid)
- **JavaScript (ES6+)** (Smooth UI interactions, menu toggles & scroll states)
- **Cloudflare Workers** (Global edge computing deployment for instant load times)
- **SEO Basics** (Structured markup & metadata optimization)

## 🚀 Key Features Implemented

### 1. Panoramic Waterfront Hero Section

A cinematic, wide-viewport entry layout designed to immediately give users the feeling of fine dining right on the Adriatic Sea.

### 2. Premium Seafood & Gastronomy Menu

A highly clean, structured component built with strict typographic hierarchy, showcasing curated menu categories with pristine layout alignment.

### 3. Asymmetric Marine Grids

Utilizing CSS Grid to effortlessly weave high-resolution ambient imagery with minimalist content blocks, bringing a high-end editorial magazine feel to the web.

### 4. Fluid Responsive Adaptation

Engineered with a responsive, mobile-first design system ensuring that the text hierarchy, image grids, and interactive elements remain flawless on everything from ultrawide screens to smartphones.

## 🧠 Learning Goals & Architecture Focus

This project was built to master:

* **Handling Fluid White Space:** Using large padding and margin systems to create a premium, breezy, and uncluttered "sea-view" digital layout.
* **Typographic Authority:** Perfecting tracking, kerning, and line-heights for clean sans-serif pairs and sophisticated display serifs.
* **Edge Deployment & Asset Delivery:** Optimizing heavy, content-rich culinary photography to stream with minimal latency through Vite's pipeline into Cloudflare's global edge nodes.

---

## 🔍 Performance & Web Fundamentals Practiced

* **Vite Asset Optimization:** Automated bundle splitting, minification, and caching-ready asset hashing.
* **Cloudflare Edge Infrastructure:** Deploying the optimized `dist/` builds directly to global nodes for instant edge serving.
* **Semantic HTML Construction:** Ensuring accessibility and clean SEO indexation using structured structural tags (`<header>`, `<main>`, `<section>`).

## 🛠 How to Use & Modify This Repo

### 1. Clone the repository

```bash
git clone [https://github.com/DroidMateOfficial/molo-restoran-opatija.git](https://github.com/DroidMateOfficial/molo-restoran-opatija.git)
cd molo-restoran-opatija

```

### 2. Install dependencies

```bash
npm install

```

### 3. Run the local development server (with HMR)

```bash
npm run dev

```

### 4. Build optimized files for production

```bash
npm run build

```

*Vite will compile and compress everything into the `dist/` folder, completely optimized for Cloudflare deployment.*
