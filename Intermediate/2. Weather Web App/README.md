# Weather Intelligence App

An ultra-modern weather dashboard powered by the Visual Crossing Weather API.

---

## 🚀 Overview

This project demonstrates how to build a **real-world API-driven frontend app** with:

- Live weather fetching
- Search-based location input
- Hourly forecast rendering
- Modern UI design (glassmorphism)
- State-driven DOM updates

---

## ✨ Features

- City-based weather search
- Current temperature + conditions
- Wind speed + rain probability
- 24-hour forecast view
- Refresh button
- Default location loading
- Responsive modern UI

---

## 🧠 Architecture

- API-driven state
- DOM rendering functions
- Separation of concerns:
  - fetch logic
  - render logic
  - UI events

---
