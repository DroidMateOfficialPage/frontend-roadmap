# Temperature Converter

A modern utility app for converting temperature units.

---

## 🚀 Overview

This project demonstrates:

- DOM manipulation
- Form validation
- Conditional UI states
- Mathematical conversions in JavaScript

---

## ✨ Features

- Celsius ↔ Fahrenheit ↔ Kelvin conversion
- Smart button enabling/disabling
- Instant result display
- Clean modern UI
- Input validation

---

## 🧠 Conversion Logic

All values are normalized to Celsius first:
* F → C: (F - 32) × 5/9
* K → C: K - 273.15

Then converted to target unit.
