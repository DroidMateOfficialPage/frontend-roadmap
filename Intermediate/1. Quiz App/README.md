# Quiz App

A modern interactive quiz application built with HTML, CSS, and JavaScript.

---

## 🚀 Overview

This project demonstrates how to build a **state-driven frontend application** using vanilla JavaScript.

It simulates a real quiz system with:

- Start screen
- Question flow system
- Instant answer validation
- Score tracking
- Timer per question
- Final results screen

---

## ✨ Features

- JSON-based quiz engine
- Dynamic question rendering
- Instant correct/wrong feedback
- Score system
- Countdown timer (60s per question)
- Automatic question progression
- Final results summary

---

## 🧠 State Management Logic

The app uses simple state variables:

- `currentIndex` → tracks question
- `score` → tracks correct answers
- `timeLeft` → countdown timer
- DOM-driven UI rendering
