# Custom Dropdown Component

A modern custom dropdown built using HTML, CSS, and JavaScript.

---

## 🚀 Overview

This project recreates a native select dropdown using custom UI logic.

It focuses on:

- DOM manipulation
- Event handling
- UI state management
- Component-based thinking

---

## ✨ Features

- Custom open/close behavior
- Smooth interactive states
- Selected item highlighting
- Outside click detection
- Clean modern UI design
- Glassmorphism styling

---

## 🧠 Core Logic

- Toggle state: `.open`
- Selected state: `.active`
- Event delegation for options
- Document-level click listener for closing
