# Pomodoro Focus Timer

A modern Pomodoro productivity app built with vanilla JavaScript.

---

## 🚀 Overview

This app implements the Pomodoro Technique:

- Work intervals
- Short breaks
- Long breaks after 4 cycles

---

## ✨ Features

- Start / Pause / Reset timer
- Configurable session durations
- Automatic session switching
- Work session counter
- Sound notification on session end
- Clean modern UI

---

## 🧠 Core Logic

State machine:
work → short break → work → short break → work → long break
