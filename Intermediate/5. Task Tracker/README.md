# Task Tracker App

A modern productivity task tracker built with vanilla JavaScript.

---

## 🚀 Overview

This app demonstrates a **real state-driven UI pattern** using JavaScript arrays and DOM re-rendering.

---

## ✨ Features

- Add new tasks
- Mark tasks as complete/incomplete
- Delete tasks
- Auto sorting (pending first, completed last)
- Dynamic UI re-rendering
- Clean modern UI design

---

## 🧠 Core Concept

Single source of truth: tasks[] → renderTasks() → DOM
Any change updates state → then UI is re-rendered.
