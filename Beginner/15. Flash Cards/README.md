# Flash Cards App

A modern flashcard application built using React and component-based architecture.

This project demonstrates state management, reusable components, and UI interaction patterns commonly used in modern frontend frameworks.

---

## 🚀 Project Overview

Flashcards are widely used for:

* Learning programming concepts
* Memorization training
* Exam preparation
* Language learning apps

This project allows users to:

* View flashcards one at a time
* Flip cards to reveal answers
* Navigate between cards
* Track progress visually

---

## ✨ Features

* React component-based architecture
* Card flip animation (3D CSS transform)
* Progress tracking bar
* Previous / Next navigation
* Circular navigation (looping cards)
* Clean modern UI

---

## 🛠 Technologies Used

* React (Vite)
* JavaScript (ES6+)
* CSS3
* Flexbox
* Component state (useState)
* Props system

## 🧠 How It Works

1. Flashcards are stored in a static array
2. App keeps track of current index (state)
3. Clicking Next/Prev updates state
4. Card flips using local component state
5. Progress bar updates dynamically
