# Single-Page HTML CV

A clean, semantic, and SEO-optimized single-page CV built using only HTML.  
This project focuses on structure, accessibility, and search engine optimization — no CSS involved.

---

## 🚀 Project Overview

This CV project demonstrates how to build a professional personal webpage using only **semantic HTML5**.  
It is designed to be:

- SEO-friendly
- Social media ready (Open Graph tags)
- Easy to extend with CSS in future projects
- Fully structured for accessibility and readability

---

## 🧠 Key Features

### ✅ Semantic HTML
Proper use of:
- `<header>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`
- `<address>`

This ensures better accessibility and SEO ranking.

---

### 🔍 SEO Optimization
Includes:
- Meta title
- Meta description
- Meta keywords
- Meta author

These help search engines understand page content.

---

### 🌍 Open Graph Tags
Optimized for social sharing:
- Title
- Description
- Image
- URL

Perfect for LinkedIn, Facebook, and other platforms.

---

### 🎯 Favicon Support
A favicon is included to improve branding and browser tab recognition.
