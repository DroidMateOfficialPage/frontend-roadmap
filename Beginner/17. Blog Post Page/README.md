# Modern Blog Post UI

A modern, responsive, and semantic blog post layout built with HTML, CSS, and JavaScript.

---

## 🚀 Overview

This project demonstrates how to build a **real-world blog post UI** using modern frontend practices.

It focuses on:

- Semantic HTML structure
- Accessibility-first markup
- Modern UI/UX design patterns
- Lightweight JavaScript enhancement

---

## ✨ Features

- Sticky navigation header
- Scroll progress indicator
- Modern typography system
- Responsive layout
- Semantic blog structure
- Accessible image + caption system
- Code block styling

---

## 🛠 Tech Stack

- HTML5 (semantic layout)
- CSS3 (modern UI + glass effects)
- JavaScript (scroll interaction)
- Flexbox + responsive design
