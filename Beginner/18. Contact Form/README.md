# Accessible Contact Form

A semantic, accessible HTML contact form built with native browser validation and proper form structure.

---

## 🚀 Overview

This project focuses on building a **real-world contact form structure** using only HTML and CSS principles, without JavaScript logic.

It simulates how data is sent to a backend server.

---

## ✨ Features

- Fully semantic HTML form
- Accessible labels for all inputs
- Required field validation
- Email validation using native browser API
- Radio group inside fieldset + legend
- Checkbox for optional newsletter
- Clean modern UI styling
- Focus states for accessibility

---

## 🧠 Key Learning Goals

- How forms become HTTP requests
- Proper use of `label` + `for`
- Grouping inputs with `fieldset`
- HTML5 validation attributes
- Accessibility-first form design
