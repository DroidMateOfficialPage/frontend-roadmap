# Datepicker UI

A modern static datepicker UI built using only HTML5 and CSS3.

This project focuses on layout structuring, CSS Grid, Flexbox, and positioning techniques to create a clean and reusable UI component that can later be enhanced with JavaScript functionality.

---

## 🚀 Project Overview

A datepicker is a common UI component used in applications for selecting dates in booking systems, calendars, forms, and dashboards.

This project demonstrates how to build a visually structured and responsive datepicker using only HTML and CSS, without any JavaScript functionality.

---

## ✨ Features

* Clean calendar grid layout
* Month navigation UI (static)
* Highlighted selected date
* Disabled previous month dates
* Responsive card design
* Modern glassmorphism styling
* Hover interactions
* Button states (Cancel / Apply)
