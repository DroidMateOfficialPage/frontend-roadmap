# Photo Showcase UI

A modern responsive photo showcase built with semantic HTML, CSS Grid, and light JavaScript interactions.

---

## 🚀 Overview

This project simulates a **real portfolio/gallery UI system** used in modern web applications.

Focus is on:

- Media semantics (images, video, captions)
- Responsive grid layout
- Accessibility best practices
- Interactive lightbox UX

---

## ✨ Features

- Responsive CSS Grid gallery
- Hover elevation effects
- Image captions using `<figure>`
- Decorative image handling (`alt=""`)
- Embedded video with poster
- Lightbox preview interaction
- Lazy loading images

---

## 🧠 Key Learning Goals

- Proper image semantics (alt vs figcaption)
- Layout systems using CSS Grid
- Handling mixed media (image + video)
- UX interaction layering with JavaScript
- Accessibility-first design thinking

## ♿ Accessibility Notes

- All meaningful images have descriptive alt text
- Decorative image uses `alt=""`
- Video includes fallback text
- Semantic `<figure>` used for grouped media
- Keyboard-safe interaction (basic click handling only)
