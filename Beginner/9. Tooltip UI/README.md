# Tooltip UI

A modern CSS-only tooltip navigation component built using HTML5 and CSS3.

This project demonstrates how to create interactive UI elements using only CSS, focusing on positioning, hover effects, and micro-interactions.

---

## 🚀 Project Overview

Tooltips are small UI elements that provide additional context when users interact with navigation items or icons.

This project shows how to build a fully functional tooltip system without JavaScript using:

* CSS positioning
* Hover states
* Transitions
* Pseudo-elements

---

## ✨ Features

* CSS-only tooltip system
* Smooth hover animations
* Floating tooltip positioning
* Arrow indicator using pseudo-elements
* Responsive navigation layout
* Glassmorphism-inspired navbar
* Clean micro-interactions
