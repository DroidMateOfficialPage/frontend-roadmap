# Restricted Textarea

A modern textarea component with live character counting and input restriction built using HTML, CSS, and JavaScript.

This project demonstrates real-time DOM manipulation, user input tracking, and UI feedback patterns commonly used in social media and messaging applications.

---

## 🚀 Project Overview

Character-limited inputs are widely used in:

* Social media posts (Twitter/X style)
* Comment sections
* Messaging apps
* Forms with constraints

This project implements a controlled textarea that:

* Tracks character input in real time
* Displays a live counter
* Prevents input beyond the limit
* Shows visual error feedback

---

## ✨ Features

* Live character counter
* Maximum character limit enforcement (200 chars)

## 🧠 How It Works

1. User types into textarea
2. JavaScript listens for input events
3. Character count updates instantly
4. If limit is reached:

   * Input is restricted
   * Border turns red
   * Warning message appears
