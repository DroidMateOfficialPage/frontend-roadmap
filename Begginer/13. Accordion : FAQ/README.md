# Accordion Component

A modern accordion UI component built using HTML, CSS, and vanilla JavaScript.

This project demonstrates dynamic UI state management, DOM manipulation, and interactive layout behavior.

---

## 🚀 Project Overview

Accordions are widely used UI components for organizing content in a compact, readable format.

They are commonly found in:

* FAQ sections
* Settings panels
* Product descriptions
* Documentation pages

This project implements an accordion where:

* Only one section can be open at a time
* Clicking a question expands its answer
* Previously opened sections automatically collapse

---

## 🧠 How It Works

1. User clicks a question
2. JavaScript detects index of clicked item
3. All sections are closed
4. If clicked section was closed → it opens
5. Active styles and content visibility update
