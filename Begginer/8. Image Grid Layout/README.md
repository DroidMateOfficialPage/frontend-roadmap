# Image Grid Layout

A responsive image grid layout built using HTML5 and CSS3 with CSS Grid.

This project focuses on mastering CSS Grid fundamentals, responsive layout design, and image positioning techniques by creating a visually structured gallery component.

---

## 🚀 Project Overview

Image grids are widely used in modern web design for:

* Portfolio galleries
* Photography websites
* E-commerce product displays
* Travel and lifestyle blogs

This project demonstrates how to build a flexible and responsive image grid using pure CSS Grid without JavaScript.

---

## ✨ Features

* CSS Grid-based layout
* Responsive design for all screen sizes
* Custom grid spanning layout
* Image hover zoom effects
* Clean visual hierarchy
* Optimized image rendering with object-fit
* Mobile-first responsive behavior
