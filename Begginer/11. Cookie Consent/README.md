# Cookie Consent Banner

A modern cookie consent banner built using HTML, CSS, and JavaScript with localStorage persistence.

This project demonstrates DOM manipulation, event handling, and basic client-side storage for user preferences.

---

## 🚀 Project Overview

Cookie consent banners are commonly used on websites to inform users about cookie usage and comply with privacy regulations.

This project implements a lightweight version that:

* Displays a consent banner on first visit
* Stores user consent in localStorage
* Hides banner on subsequent visits

---

## ✨ Features

* Floating cookie consent banner
* Accept button interaction
* Persistent user preference (localStorage)
* Smooth show/hide animations

## 🧠 How It Works

1. Page loads
2. JavaScript checks `localStorage` for consent
3. If not found → banner is shown
4. User clicks “Accept”
5. Consent is saved in localStorage
6. Banner is permanently hidden on future visits
