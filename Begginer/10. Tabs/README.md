# Tabs Component

A simple and interactive tabs component built using HTML, CSS, and vanilla JavaScript.

This project demonstrates basic DOM manipulation, event handling, and dynamic UI state management.

---

## 🚀 Project Overview

Tabs are a common UI pattern used to organize content into separate sections without navigating to different pages.

This project shows how to implement tab switching functionality using:

* HTML structure for tab groups
* CSS styling for active states
* JavaScript DOM manipulation

---

## ✨ Features

* 4-tab navigation system
* Default active tab on load
* Dynamic content switching
* Smooth fade animation
* Responsive layout
* Clean UI design
* Vanilla JavaScript (no frameworks)

## 🧠 How It Works

1. All tabs and content sections are selected using JavaScript
2. Clicking a tab triggers an event listener
3. Active classes are removed from all tabs and content
4. Selected tab gets `active` class
5. Matching content section is displayed
