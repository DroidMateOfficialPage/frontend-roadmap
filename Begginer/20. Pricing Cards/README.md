# Pricing Comparison Table

A responsive, accessible pricing comparison table built using semantic HTML, CSS, and light JavaScript enhancements.

---

## 🚀 Project Overview

This project demonstrates how to structure and present tabular data correctly using HTML tables.

It focuses on:

- Semantic HTML structure
- Accessibility best practices
- Proper table hierarchy
- Minimal UI enhancement with JavaScript

---

## ✨ Features

- Fully semantic HTML page (header, main, footer)
- Accessible table with caption
- Proper use of scope attributes
- Logical grouping using colspan
- Responsive horizontal scroll for small screens
- Hover interaction enhancement via JavaScript

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)
- Flexbox (layout structure)
