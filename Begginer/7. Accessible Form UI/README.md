# Accessible Form UI

A modern and accessible form UI built using HTML5 and CSS3.

This project focuses on creating a fully structured, user-friendly, and accessibility-first form interface that includes validation placeholders, progress tracking UI, and requirement checklist elements.

---

## 🚀 Project Overview

Forms are one of the most important UI components in web applications.

This project demonstrates how to build a modern form layout that prioritizes:

* Accessibility (a11y)
* Semantic HTML
* Responsive design
* Visual hierarchy
* User experience structure

The form includes fields for:

* Full Name
* Email
* Password
* Confirm Password

---

## ✨ Features

### Accessible Form Structure

* Proper `<label>` association using `for` attributes
* ARIA attributes (`aria-required`)
* Focus state styling for keyboard navigation
* Clear input hierarchy

---

### Password Toggle UI (Static)

A visual password toggle button is included to simulate functionality for future JavaScript enhancement.

---

### Progress Bar UI

A visual indicator showing form completion status.

* Dynamic-looking fill bar
* Percentage indicator
* Designed for future JS integration

---

### Requirements Checklist

A side panel shows form validation requirements such as:

* Full name completion
* Email validity
* Password strength
* Password matching

---

### Responsive Layout

The form adapts to different screen sizes:

* Desktop: two-column layout
* Mobile: stacked layout

## ♿ Accessibility Considerations

This project follows basic WCAG principles:

* Labels are explicitly connected to inputs
* Focus states are clearly visible
* Sufficient color contrast
* Logical tab order
* ARIA attributes for required fields
